====================================================================
  E3ProMax / Flux E3 — Быстрый запуск кодовой базы на компьютере
====================================================================

1. ЗАПУСК В ОДИН КЛИК (рекомендуется)
--------------------------------------------------------------------
- Windows 10 / 11:
  Дважды щёлкните файл Start_E3ProMax.cmd

  Что сделает скрипт автоматически:
  1) Проверит Node.js >= 20; если на ПК нет Node.js, сам один раз скачает
     и распакует официальный портативный Node.js v22.14.0 в папку .runtime\
     (установка в систему и права администратора не требуются).
  2) При первом запуске выполнит npm install в папке проекта.
  3) Запустит сервер на http://127.0.0.1:3000 (если порт 3000 занят —
     автоматически выберет свободный порт 3001..3020) и сам откроет браузер.

- macOS:
  Дважды щёлкните Start_E3ProMax.command (или выполните в терминале:
  chmod +x Start_E3ProMax.sh Start_E3ProMax.command && ./Start_E3ProMax.sh)

- Linux:
  Выполните в терминале: chmod +x Start_E3ProMax.sh && ./Start_E3ProMax.sh


2. РУЧНОЙ ЗАПУСК ЧЕРЕЗ ТЕРМИНАЛ (Node.js >= 20)
--------------------------------------------------------------------
  npm install
  npm run dev

Для production-сборки:
  npm run build
  npm start


3. СОХРАНЕНИЕ ПРОЕКТОВ И ЛОГИ НА ПК
--------------------------------------------------------------------
- data/project.json        — автосохранение изменений проекта на диске
- logs/e3promax-server.log — подробный журнал работы сервера и API
- logs/launcher.log        — журнал шагов запуска Start_E3ProMax.cmd

При локальном запуске на Windows кнопка «В E³.series» в интерфейсе
работает напрямую с локально установленным Zuken E3.series через COM.
